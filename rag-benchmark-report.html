Layman Guide

What is this? Fuche tries the smallest model first (Qwen 0.6B, ~0.8s). If it fails the heuristic gate, it escalates to Ornith 9B (~10s). If Ornith's output is rejected by Qwen-as-Judge, the query goes to Cloud ~80B. If Cloud is down, DeepSeek v4 (opencode's model) writes the answer — like asking a junior, senior, expert consultant, then the boss.

RAG: Every code fix is auto-saved and FAISS-indexed. Similar questions find old fixes as context.

KJv2: Checks actual command output for errors, not just the command text.

FAISS: 43,832 vectors, GPU-accelerated on RTX 5060. Powers the plugin RAG search and cascade command context.
